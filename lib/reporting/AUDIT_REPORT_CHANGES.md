# Section Audit Report — Redesign Summary

## What Changed

The Section Audit PDF report was redesigned from a raw table export into a structured QA audit report.

### 1. Report structure (Phase 1)

- **Title block**: "SECTION AUDIT REPORT" with subtitle "Raw Pipe Installation Records"
- **Metadata block**: Label/value grid with Project, Section, Direction, Chainage range, Total records, Generated date, Generated by. Grey background, clear hierarchy
- **Audit summary block**: Total records, All checks passed, With issues, Pass rate %. Failure breakdown by CP, Ovality, Air, Cement, Spark. Enables quick status review

### 2. Table improvements (Phase 2)

- **Grouped headers**: "Pipe Details" | "Pipe Checks" (CP, Ovality, Air, Cement, Spark) | "Inspector"
- **Zebra striping**: Alternating row backgrounds for readability
- **Column rebalance**: Pipe ID 40→52, Alignment 56→58, Inspector 48→56
- **Alignment field**: Single line "V: +35  H: R6" with adequate width
- **Failure emphasis**: N values shown in bold

### 3. Visual design (Phase 3)

- Neutral palette: black/grey text, subtle grey fills (#f3f4f6, #e5e7eb)
- No flashy colors; formal QA aesthetic
- Clear whitespace between sections

### 4. Footer (Phase 4)

- Logo
- "Generated by OnSite QA System"
- "Audit report — Raw Pipe Records"
- "APA Quality Management Systems"

### 5. Implementation

- **New**: `lib/reporting/audit-summary.ts` — computes pass/fail counts and breakdown from raw records
- **Updated**: `lib/reporting/audit-report-pdf.tsx` — full layout redesign
- **Updated**: API routes pass `direction`, `start_ch`, `end_ch`, `generatedBy`

### PDF pipeline

- **Unchanged**: React-PDF (`@react-pdf/renderer`) — no migration to Puppeteer
- Data mapping and record structure preserved
